# 직접 그려 줄 일러스트 · 아이콘 목록

당분간 화면에는 아래 **기본 이모지**를 placeholder로 넣었다.
같은 슬롯에 PNG를 주면 1:1로 갈아끼우면 된다.

앱 프레임은 모바일 `max-w-md`(**448px**). 시안 기준 폰은 **390×844**.
아래 **화면 크기**는 지금 코드의 CSS 픽셀이다(이모지 `font-size` / 박스 `width×height`).
프로크리에이트는 그보다 크게 그리고, 넣을 때 줄인다.

---

## 프로크리에이트 공통 규칙

캔버스는 슬롯마다 다르게 만들지 말고, 아래 **3종만** 쓰면 된다.
같은 세트끼리 선 굵기·아웃라인 색이 맞아야 한다.

| 캔버스 | 픽셀 | 쓰는 슬롯 | 프로크리에이트 새 캔버스 |
| --- | ---: | --- | --- |
| **A 아이콘** | 1024×1024 | 탭, 카테고리, 이동, 담당, 티켓 비행기 | 정사각, 투명 배경 |
| **B 중형** | 1536×1536 | 날씨, 숙소, FAB, 구름, 타임캡슐 아이콘, 푸터 | 정사각, 투명 배경 |
| **C 히어로** | 2048×2048 | 스플래시 섬, 마스코트 전신, D-Day 장식 | 정사각, 투명 배경 |

권장(그리기 편의. 화면 픽셀과 1:1은 아님):

- **DPI**: 72 (웹 PNG. 300으로 그려도 되지만 내보낼 때 픽셀 수가 위 표면 된다)
- **색 프로필**: sRGB
- **배경**: 체크무늬(투명). 크림/하늘색 배경은 앱이 이미 깔고 있다. 그림에 배경색을 넣지 말 것
- **세이프 존**: 가장자리 **12.5%** 는 비운다. A면 안쪽 768×768, B면 1152×1152, C면 1536×1536 안에 본체
- **아웃라인**: 진한 갈색 `#3D2B1F`, 둥근 캡. A 캔버스 기준 선 굵기 **28–36px**. B는 **40–52px**, C는 **56–72px** 정도로 키운다 (시안: bold rounded outline)
- **채색 힌트** (지금 UI 토큰 / 시안 카피. 완전히 맞출 필요는 없음):
  - 크림 `#FFF8EE` · 귤 `#FF9F43` · 하늘 `#B8E3F5` / `#A8D8EA` · 핑크 `#FFB4C8` · 본문갈색 `#3D2B1F`
- **내보내기**: PNG, 투명, 한 슬롯당 파일 1개. `@2x`/`@3x` 따로 안 뽑아도 된다
- **파일 이름**: `public/illustrations/{슬롯이름}.png`  
  예: `nav-home.png`, `mascot-tangerine.png`
- **포맷**: PNG 우선. SVG는 프로크리에이트에서 안 나오니 받지 않는다
- **수정/삭제 아이콘**: 그리지 않는다. Lucide `PencilLine` / `Trash2`를 쓴다
- **스플래시 스피너**: CSS. 그리지 않는다

한 레이어에 여러 아이콘을 그리고 자르지 말 것. 슬롯 = 파일 1개.

## 스플래시 (로딩)

지금 코드: 구름 `text-4xl`(36px), 섬 `text-6xl`(60px). 그림으로 바꾸면 섬은 더 크게 둘 예정(권장 표시 **200×200**).

| 슬롯 | 지금 | 캔버스 | 화면 표시 | 용도 |
| --- | --- | --- | ---: | --- |
| splash-terrarium | 🏝️ | C 2048 | 200×200 | 유리돔/섬. 하늘→크림 그라데이션 **위** 중앙. 배경 투명 |
| splash-cloud | ☁️ | B 1536 | 48×48 | 돔 위 작은 구름. **같은 그림 1장**을 3번 쓴다. 방향만 다른 클라우드 3종을 주면 더 좋음 (`splash-cloud-1/2/3`) |
| splash-spinner | (CSS) | — | 32×32 | 그리지 않음 |

## 하단 탭

탭 버튼 높이 `min-h-12`(48). 아이콘은 `text-base`(16px). 다섯 장 선 굵기·무게감 맞출 것.

| 슬롯 | 지금 | 캔버스 | 화면 표시 |
| --- | --- | --- | ---: |
| nav-home | 🏠 | A 1024 | 24×24 (지금 16. 그림 넣으면 24로 키움) |
| nav-planner | 📅 | A 1024 | 24×24 |
| nav-list | 📍 | A 1024 | 24×24 |
| nav-budget | 👛 | A 1024 | 24×24 |
| nav-prep | ✅ | A 1024 | 24×24 |

활성/비활성은 코드가 색만 바꾼다. **한 색(아웃라인+채색) 한 장**이면 된다. 회색 버전 따로 안 그려도 됨.

## 리스트 · 플래너 카테고리

리스트/비용 카드 아이콘 박스는 **48×48** (`size-12`), 안 그림은 `text-xl`(20px).
그림 넣으면 박스 안 **32×32**.
